# 🎮 Hangman Game (Python + Tkinter)

A simple **Hangman Game** built using Python and Tkinter GUI.  
Players can guess letters to reveal the hidden word. Categories include **Countries, Capitals, and Freedom Fighters**.

---

## ✨ Features
- GUI built with Tkinter
- Random word selection from categories
- Underscore display with revealed letters
- Hangman drawing step by step on wrong guesses
- Win/Lose popup messages
- Restart option to play again

---

## 🖥️ Requirements
- Python 3.x
- Libraries:
  - `tkinter` (comes with Python)
  - `requests`
  - `beautifulsoup4`

Install missing libraries using:
```bash
pip install requests beautifulsoup4
